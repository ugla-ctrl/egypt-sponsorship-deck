# Egypt Eclipse · Sponsorship Deck

Web deck for Egypt Eclipse sponsorship outreach. Hand-coded single `index.html`,
hosted on GitHub Pages.

## Status
Scaffold only. Slide content to be added once the sponsorship storyboard is ready.

## View
Open `index.html`, or the GitHub Pages URL. Arrow keys, click/tap edges, or swipe.
Deep link to a slide with `#3`.

## Structure
- `index.html`: the deck (slides are `.slide` sections)
- `media/`: images and video
